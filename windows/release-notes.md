## 🇬🇧 MusicHub Classic – 1.2.1

The MusicHub Classic package includes the Android application and the Windows desktop application.

### Android – Universal
- **Platform:** Android
- **Minimum Android version:** 7.0 (Nougat, API 24)
- **APK size:** approximately 320 MiB (335.5 MB)
- **Technology:** Mozilla GeckoView, based on Mozilla Firefox browser technology.
- Compatible with phones and tablets; the interface adapts to screen size and orientation.
- Music playback and media controls, depending on player and Android system support.

### Windows – x64
- **Platform:** Windows 64-bit (x64)
- **Target systems:** Windows 7, 8, 8.1, 10 and 11 (64-bit).
- **EXE size:** approximately 66 MiB (69.2 MB).
- **Technology:** Electron 22.3.27, based on Chromium.
- Only the x64 installer is available; there is no 32-bit version.

**Windows security note:** Electron 22 is end-of-life and no longer receives security updates. This legacy version is used for compatibility with older Windows versions. Avoid entering passwords or sensitive information in the application.
